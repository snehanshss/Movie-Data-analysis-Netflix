Netflix Data Analysis



This project explores and analyzes Netflix's movie and TV show dataset to uncover interesting trends, insights, and patterns in the content available on the platform.



---



Project Overview

The goal of this project is to perform exploratory data analysis (EDA) on the Netflix dataset using Python to answer questions such as:

Q1. What is the most frequent genre in the dataset?

Q2. What genre has the highest votes? 

Q3. what movie got highest popularity? 

Q4. What movie get lowest popularity?

Q5. Which year has the most filmed movies? 



---



Technologies Used

\- Python

\- Pandas, NumPy

\- Matplotlib, Seaborn

\- Jupyter Notebook
